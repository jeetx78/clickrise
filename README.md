# ClickRise Productions — V2

A single-page, conversion-focused Next.js site based on the ClickRise upgrade brief.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Notes
- Contact is intentionally a homepage section, not a separate page.
- Favicon lives at `app/favicon.png` and is declared in `app/layout.tsx`.
- Replace the abstract case-study backgrounds with approved project imagery when available.
- Replace placeholder contact email/WhatsApp number and social links before launch.
- The contact form currently shows a client-side success state; connect it to your preferred form backend before production.
